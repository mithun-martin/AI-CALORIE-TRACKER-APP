# 🥗 AI Calorie Tracker & Food Recommendation App

This is a Flask-based web application that helps users calculate their daily calorie needs (BMR and TDEE), set dietary goals, and receive AI-generated food suggestions tailored to their preferences and targets.

🔗 **Live Demo**: [https://your-heroku-app-name.herokuapp.com](https://your-heroku-app-name.herokuapp.com)

---

## 🚀 Features

- 🧮 **Calorie Calculator**: Compute BMR & TDEE based on user details.
- 🎯 **Goal-based Planning**: Set weight goals (gain, lose, maintain) and see adjusted calorie targets.
- 🤖 **AI-Powered Food Suggestions**: ML model recommends personalized food plans based on user input.
- 📊 **Clean UI**: Intuitive forms and result pages styled with Tailwind CSS.
